SANA: offline AI voice assistant

A JARVIS-style personal assistant that runs entirely on a local PC: a local language model, on-device speech recognition and synthesis, long-term memory, an animated desktop orb, and control of ESP32 hardware.

Period Nov 2026Status Active developmentLast updated 25 Nov 2026

Why build it

I wanted an assistant that keeps my data on my own machine and can talk to my own hardware. The language model, speech recognition, text-to-speech and memory all run locally; only the optional web tools touch the internet, and offline mode removes them.

How it works

A wake-word listener with voice-activity detection feeds faster-whisper for speech-to-text. An agent loop passes the request to a local model through Ollama, which can call 22 skills; tool arguments are validated and repaired before anything runs. Piper speaks the answer, and SQLite stores long-term memory, reminders and notes.

Talking to hardware

SANA switches ESP32 devices and reads their sensors over MQTT, with a mock mode until a real device is connected. Shell commands only run after I approve the exact command.

Choosing the model

On a CPU-only i5 laptop, a 4B instruct model handled all 9 of my test tasks. A 3B model was about twice as fast but invented results on 2 tasks instead of using its tools. Hardware settings live in one config file, so adding a GPU or a separate server needs no code changes.

What's next

A trained wake-word model, vision through a local model once a GPU is added, a phone client, and a multi-node ESP32 network.

Highlights

  • 22 skills: app and media control, file search, reminders and notes, an exact calculator, web search, and shell commands that run only after approval.
  • Hands-free wake-word mode with faster-whisper speech-to-text and Piper text-to-speech, all on-device.
  • Switches ESP32 devices and reads their sensors over MQTT.
  • Swappable model providers (local Ollama by default) and a strict offline mode.
  • Transparent animated 'universe' orb that shows when it is listening, thinking and speaking.
